# Архитектура курсового приложения «Кошелёк»

Тема: «Разработка органайзера личных расходов с категориями, месячными отчётами и диаграммами с использованием языка JavaScript». Исходный код написан на TypeScript, который компилируется в JavaScript. Приложение работает в браузере, данные сохраняются в `localStorage`.

## Структура

Репозиторий содержит два самостоятельных проекта:

- `frontend/` — приложение React. `src/App.tsx` содержит общую оболочку, маршруты, состояние расходов и профиля, формы добавления и редактирования. `src/pages/MonthlyReport.tsx` строит месячную сводку и диаграммы. `src/App.css`, `src/Forms.css`, `src/index.css` задают оформление. `src/main.tsx` — точка входа. `src/App.test.tsx` — интеграционные тесты. Файлы `vite.config.ts`, `jest.config.ts`, `eslint.config.js`, `tsconfig*.json` — настройки инструментов.
- `ui-library/` — библиотека повторно используемых компонентов. `src/ExpensesTable/` содержит таблицу с фильтрацией и сортировкой; `src/CategorySummary/` — сводку по категориям и полосовые диаграммы. В каждой папке находятся компонент, стили и тесты. `src/index.ts` экспортирует публичный API; остальные файлы в корне настраивают сборку, тесты и линтер.
- `screenshots/` — изображения примеров работы для README. `architecture.md`, `mvp.md`, `README.md` — документация в корне.

Папки `node_modules`, `dist`, `coverage` не включаются в репозиторий.

## Компоненты и страницы

`frontend` предоставляет оболочку `App` с боковой навигацией и состоянием, главную страницу со статистикой и пятью последними расходами, страницу расходов с операциями, страницу категорий, страницу профиля, страницу месячного отчёта `MonthlyReport` и сообщение для неизвестного маршрута. Формы добавления/редактирования расходов и профиля, а также подтверждение удаления работают из общей оболочки.

`ui-library` предоставляет `ExpensesTable` для полной истории операций и `CategorySummary` для распределения трат. `frontend` импортирует оба компонента из публичного API библиотеки и отображает их на страницах расходов, категорий и обзора.

## Роутинг

Все страницы находятся внутри общей оболочки `App`, открываются напрямую по URL и доступны из бокового меню. Параметризованные и защищённые маршруты в этом локальном однопользовательском MVP не предусмотрены.

| Маршрут | Страница |
| --- | --- |
| `/` | Обзор: карточки статистики, последние расходы, сводка |
| `/expenses` | Полная таблица расходов, фильтр, сортировка, редактирование |
| `/categories` | Расходы текущего месяца по категориям |
| `/reports` | Выбор месяца, показатели и диаграммы |
| `/profile` | Имя и месячный бюджет |
| любой другой | Сообщение «Страница не найдена» |

Переходы используют `history.pushState`; обработчик `popstate` обеспечивает работу кнопок браузера «Назад» и «Вперёд». Vite отдаёт `index.html` при прямом переходе на маршрут в режиме разработки.
